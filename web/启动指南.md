# 一键启动指南

## 1. 启动 Flask 问卷项目（端口 6006）

```bash
cd /root/问卷 && nohup python app.py 6006 > /tmp/questionnaire.log 2>&1 &
```

验证：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:6006` 返回 200

## 2. 启动 Streamlit 项目（端口 8501）

```bash
cd /root/web && nohup streamlit run streamlit_app.py --server.port 8501 --server.address 0.0.0.0 > /tmp/streamlit.log 2>&1 &
```

验证：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8501` 返回 200

## 3. 启动 EcoEval 卫生经济学评价项目（端口 6007）

### 3.1 启动 Flask 后端

```bash
cd /root/EcoEval && nohup python app.py > /tmp/ecoeval.log 2>&1 &
```

验证：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:6007` 返回 200

### 3.2 启动 Nginx 反向代理（端口 8001）

```bash
nginx
```

> Nginx 负责将 `/ecoeval/` 前缀剥离后转发到本地 6007 端口，配置文件位于 `/etc/nginx/sites-available/ecoeval`。

验证：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8001/ecoeval/` 返回 200

## 4. 启动 Cloudflare Tunnel

```bash
nohup cloudflared tunnel run 9d405ab8-78c6-4dd1-82c0-866b170362f9 > /tmp/cloudflared.log 2>&1 &
```

验证：`cat /tmp/cloudflared.log` 看到 `Registered tunnel connection`

> Tunnel 的 ingress 规则（`/root/.cloudflared/config.yml`）将 `/ecoeval/*` 转发到本地 8001（Nginx），再经 Nginx 反代到 EcoEval Flask 应用（6007）。

## 一键启动脚本

```bash
cd /root/问卷 && nohup python app.py 6006 > /tmp/questionnaire.log 2>&1 &
cd /root/web && nohup streamlit run streamlit_app.py --server.port 8501 --server.address 0.0.0.0 > /tmp/streamlit.log 2>&1 &
cd /root/EcoEval && nohup python app.py > /tmp/ecoeval.log 2>&1 &
nginx
nohup cloudflared tunnel run 9d405ab8-78c6-4dd1-82c0-866b170362f9 > /tmp/cloudflared.log 2>&1 &
```

> 注意：若 Nginx 已在运行，再次执行 `nginx` 会因端口占用报错，可改用 `nginx -s reload` 重新加载配置。
